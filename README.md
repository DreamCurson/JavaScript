# 🧰 Boîtes Modales en JavaScript (POO)

Ce projet a pour objectif de créer des **boîtes modales dynamiques** en JavaScript en appliquant les principes de la **programmation orientée objet (POO)** :

- **Encapsulation**
- **Héritage**
- **Polymorphisme**

Chaque boîte modale peut :
- ✅ S’afficher dynamiquement dans la page HTML  
- ✅ Se fermer proprement  
- ✅ Afficher un contenu personnalisé (texte, HTML, etc.)
